## Быстрый запуск

Для работы приложения необходимо запустить две части: **Backend (Strapi)** и **Frontend (Vue 3)** в двух отдельных терминалах.

### 1. Бэкенд (Strapi CMS)

```bash
cd backend
npm install
npm run develop
```

- API и админка Strapi будут доступны по адресу: **`http://localhost:1337`**
- Панель администратора Strapi: **`http://localhost:1337/admin`**

---

### 2. Фронтенд (Vue 3 + Vite)

```bash
cd frontend
npm install
npm run dev
```

- Клиентское приложение будет доступно по адресу: **`http://localhost:5173`**
